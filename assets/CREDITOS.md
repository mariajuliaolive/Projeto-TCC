## Sons

Todos os arquivos em `assets/sounds/` são **provisórios**, sintetizados
pelo script `ferramentas/gerar-sons.py`, escrito para este projeto. Não há
material de terceiros.

Ao substituir por sons reais, registrar aqui cada arquivo no mesmo
formato dos modelos.
