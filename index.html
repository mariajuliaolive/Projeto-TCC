Sobre o projeto

O que é este sistema

Um protótipo de Realidade Virtual desenvolvido como Trabalho de Conclusão de Curso. Ele simula a presença de animais associados a fobias específicas em ambientes virtuais, organizados em níveis progressivos de aproximação, para estudar como as pessoas percebem e interagem com esse tipo de estímulo em VR.

  • Acesso pelo navegador

    Nada para instalar. A experiência abre em uma página web comum.

  • Cinco níveis progressivos

    Do estímulo distante até a interação direta, com avanço controlado por quem usa.

  • Multiplataforma

    Computador, celular e óculos de Realidade Virtual compatíveis com WebXR.

  • Finalidade acadêmica

    Construído para avaliar usabilidade, imersão, interação e percepção.

Como funciona

Três passos

  1. 1

    Escolha um estímulo

    Selecione qual dos cinco cenários deseja explorar.

  2. 2

    Escolha o nível

    Do nível 1, com o estímulo distante, até o nível 5, com interação direta.

  3. 3

    Entre no ambiente

    A cena abre no navegador. É possível sair a qualquer momento.

Aviso: o sistema é um protótipo acadêmico desenvolvido para avaliação de interação, usabilidade e experiência em Realidade Virtual. Não possui finalidade de diagnóstico ou tratamento.
